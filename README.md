# BLEEDLINE

Студия музыкальных edit-видео с текстом песни для Windows: TikTok, Reels, Shorts.

Здесь лежат только установщик и обновления. Код программы — в закрытом репозитории.

## Установка

1. Откройте [последний выпуск](../../releases/latest) и скачайте **BLEEDLINE-Setup.exe** (около 30 КБ).
2. Запустите его. Windows может показать «Система Windows защитила ваш компьютер» — установщик не подписан цифровой подписью. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Нажмите «Установить». Остальное (около 3 ГБ) установщик скачает сам в 6 потоков; если связь оборвётся — запустите его снова, загрузка продолжится с того же места.

Права администратора не нужны. Программа ставится в `%LOCALAPPDATA%\Programs\BLEEDLINE`, появляется ярлык на рабочем столе и в меню «Пуск».

## Обновления

Программа сама сообщает о новой версии и показывает, что нового. Нажмите «Обновить» — скачаются только изменившиеся части.

## Что нужно

- Windows 10 или 11 (64 бита), от 8 ГБ памяти, около 10 ГБ свободного места.
- Видеокарта NVIDIA ускоряет автосинхронизацию текста, но не обязательна.
- При первой автосинхронизации программа один раз скачает модели распознавания (около 4,4 ГБ).

## Удаление

«Параметры Windows» → «Приложения» → BLEEDLINE → «Удалить». Ваши проекты и готовые видео останутся.
